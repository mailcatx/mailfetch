# mailfetch

Hey there! `mailfetch` is a  system-info tool, my first program ever.



## Installation

Disclaimer: The program works only on linux, and was tested only on Arch, so, it's unconfirmed that it works on other distros.



To install mailfetch, just run following commands:

```bash
git clone https://github.com/mailcatx/mailfetch.git
cd mailfetch
makepkg -si
```



Then, you can run it  with

```bash
mailfetch
```
